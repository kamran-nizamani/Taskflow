# TaskFlow

TaskFlow is a task-management application currently deployed on Vercel.

## Development roadmap

1. Preserve the current MVP
2. Add persistent database storage
3. Add authentication and user-specific tasks
4. Add projects and advanced task management
5. Add calendar and notifications
6. Add AI-assisted task creation and planning
7. Add developer-focused integrations

## Repository status

The repository is being established from the currently deployed TaskFlow MVP. The source structure will be documented as it is recovered and migrated.
